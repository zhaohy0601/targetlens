# Open-Source Scope

TargetLens is a clean public repository derived from the research direction of the existing HerbLens workspace. The old workspace remains untouched and is not copied wholesale.

## Included

- original TargetLens contracts and orchestration code;
- minimal public examples and tests;
- documentation of interfaces, evaluation, and scientific limitations;
- adapters only when their code and dependencies have compatible licenses.

## Excluded by default

- `.env` files and credentials;
- private server paths, deployment scripts, logs, and database dumps;
- full-text literature and embedding indexes unless redistribution is explicitly permitted;
- model weights unless their license permits redistribution;
- user uploads and generated run artifacts;
- old HerbLens consumer-facing behavior as a claimed TargetLens feature.

## Scientific wording

Use “model prediction”, “structure calculation”, or “computational ranking” where appropriate. Do not use “confirmed binder”, “effective drug”, “safe compound”, or “discovered drug” without independent experimental evidence.
